# Кабинет в GitHub Codespaces

Это виртуальная машина в браузере — ничего не нужно устанавливать.

1. Первое создание занимает **3–5 минут**: ставятся зависимости, создаётся база с демо-данными, собирается кабинет.
   Ход работы виден в терминале внизу.
2. Когда всё готово, кабинет **откроется в новой вкладке** браузера.
   Если не открылся: внизу вкладка **PORTS** → строка **3000** → значок 🌐 (*Open in Browser*).
3. Войдите под тестовым аккаунтом. Пароль у всех: **`Gorizont2026`**

| Логин | Кто |
|---|---|
| `dima.sokolov` | студент ФИТ, 3 курс |
| `timur.kim` | студент ФИТ, та же группа |
| `anna.belova` | студентка ЭФ, 1 курс |
| `dekanat.fit` | сотрудник деканата ФИТ |
| `dekanat.ef` | сотрудник деканата ЭФ |

**Вернуть демо-данные к исходным:** в терминале `npm run db:seed`.

**Не забудьте остановить Codespace**, когда закончите (github.com/codespaces → «…» → *Stop codespace*),
иначе он расходует бесплатную квоту. Через 30 минут бездействия он остановится сам.

> Ссылка на Codespace доступна только вам: по умолчанию порт приватный. Для жюри будет отдельный сервер.

# Шаблоны промптов

Проверенные заготовки для постановки задач ИИ-ассистентам. Хороший промпт содержит:
**контекст → задачу → ограничения → критерий готовности**.

## 1. Новый раздел интерфейса

```text
Прочитай CLAUDE.md, docs/PRD.md (раздел 5.X) и docs/DESIGN.md.
Сделай страницу «<Раздел>» для кабинета студента.

Что показать: <список данных>.
Главный вопрос студента на этом экране: «<вопрос>».
Ограничения:
- данные берутся только через lib/data/* с фильтром по сессии;
- mobile-first, проверка на 360 px;
- состояния загрузки, пустоты и ошибки;
- только компоненты и токены из DESIGN.md.
Готово, когда: страница открывается, проходит линтер и сборку,
на 360 px нет горизонтальной прокрутки. После — запусти ui-reviewer.
```

**Пример:**
```text
Сделай страницу «Расписание». Что показать: занятия на сегодня и неделю,
тип, аудиторию, преподавателя; переносы — как «было → стало».
Главный вопрос: «Куда и когда мне идти?» …
```

## 2. Функция с доступом к данным

```text
Добавь серверное действие <название>.
Требования безопасности из CLAUDE.md, пункт 2: фильтр по studentId из сессии,
валидация входа через Zod, ответ 404 для чужих объектов.
Напиши тест: студент A не может получить/изменить объект студента B.
После — запусти security-reviewer и исправь найденное.
```

## 3. Исправление ошибки

```text
Ошибка: <что видно / текст ошибки / скриншот>.
Шаги воспроизведения: <1, 2, 3>.
Ожидалось: <…>.
Сначала найди причину и объясни её простыми словами, потом исправь.
Не меняй ничего, что не относится к ошибке.
```

## 4. Вымышленные данные

```text
Сгенерируй seed-данные для prisma/seed.ts: <N> студентов, группы, расписание на 2 недели,
оценки за 2 семестра. Все ФИО и номера — вымышленные и правдоподобные,
без совпадений с известными людьми. Добавь 2 переноса и 1 отмену занятия на текущей неделе.
```

## 5. Ревью перед коммитом

```text
Проверь изменения в этой ветке по CLAUDE.md: безопасность доступа к данным,
секреты в коде, mobile-first, три состояния экранов. Выдай список проблем по важности.
```

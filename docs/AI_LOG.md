# Дневник работы с ИИ

Здесь фиксируется, как проект создавался с помощью нейросетей: какие задачи ставились,
какие промпты сработали, где ИИ ошибался и как это исправлялось.
Из этого файла и папки `screenshots/` собирается итоговый отчёт для жюри.

## Как вести

После каждой заметной задачи добавляй запись по шаблону (новые — сверху):

```markdown
### ГГГГ-ММ-ДД · Этап N · Короткое название
**Инструмент:** Claude Code / Cursor / Kandinsky / …
**Задача:** что нужно было сделать
**Промпт:** ключевой запрос (дословно или близко к тексту)
**Результат:** что получилось, какие файлы созданы
**Ошибки ИИ и исправления:** что пошло не так и как поправили (если было)
**Сделано вручную:** что человек сделал сам
**Скриншоты:** screenshots/…
```

### 2026-11-08 · Этап 0 · README проекта
**Инструмент:** Claude Code
**Задача:** заполнить README по описанию конкурса.
**Промпт:** «Ты мой помощник в реализации проекта по созданию личного кабинета студента.
Подробное описание проекта прикрепляю. Зайди в мой репозиторий, посвящённый этому проекту
на GitHub, и заполни README информацией о проекте» + файл с условиями конкурса.
**Результат:** README с проблемой, обязательным ядром, требованиями, безопасностью,
заготовками для тестовых аккаунтов и стека, планом и критериями оценки.
ИИ намеренно оставил пустыми стек, ссылку и аккаунты, чтобы не выдумывать несуществующее.
**Ошибки ИИ и исправления:** после отправки в GitHub автоматическая проверка сообщила,
что коммит «не отправлен». ИИ сверил хеш коммита локально и на GitHub, выяснил, что это
ложное срабатывание из-за сокращённого клонирования (`--depth 1`), и настроил отслеживание ветки.
**Сделано вручную:** создание репозитория на GitHub, постановка задачи.

# Скриншоты процесса

Скриншоты для отчёта жюри: от первой идеи до готового кабинета, включая неудачные варианты.

## Именование

```
<этап>-<дата>-<что>-<вариант>.png
```

Примеры:
- `0-2026-11-08-roadmap-chat.png` — диалог с ИИ о дорожной карте
- `1-2026-11-09-logo-v1-rejected.png` — отклонённый вариант логотипа
- `3-2026-11-12-schedule-mobile-360.png` — расписание на телефоне

## Что обязательно снять

- [ ] Ключевые диалоги с ИИ (по одному на этап)
- [ ] Варианты логотипа и макетов — удачные и неудачные
- [ ] Каждый раздел кабинета: телефон (360 px) и компьютер
- [ ] Ошибки ИИ и их исправление («до / после»)
- [ ] Проверка безопасности: попытка открыть чужую заявку → «Не найдено»
- [ ] Кабинет сотрудника: смена статуса заявки

Каждый скриншот упоминается в соответствующей записи `../AI_LOG.md`.

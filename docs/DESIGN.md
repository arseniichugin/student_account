# Дизайн-система

> Статус: **черновик**. Палитра, шрифт и логотип утверждаются на этапе 1.
> Значения ниже — стартовое предложение, их можно менять.

## 1. Принципы

1. **Сначала телефон.** Макет рисуется на 360 px, потом расширяется.
2. **Ответ, а не таблица.** На каждом экране главное — ответ на вопрос студента
   («Следующая пара через 25 минут, ауд. 305»), детали — ниже.
3. **Изменения заметны.** Переносы, отмены, новые статусы — цветом, иконкой и текстом
   (не только цветом — ради доступности).
4. **Никаких тупиков.** У пустого экрана есть объяснение и действие, у ошибки — кнопка «Повторить».
5. **Спокойный интерфейс.** Один акцентный цвет, много воздуха, минимум рамок.

### Цвета оценок (буквы ECTS)

Шкала и цвета — одна константа `GRADE_SCALE` в `lib/grades/scale.ts` (у каждой буквы `tone.text`,
`tone.bg`, `tone.fill`, `tone.stroke` — классы Tailwind, и `cssVar` — для SVG). Токены `--grade-<буква>`
(текст) и `--grade-<буква>-soft` (фон «плашки»), классы `text-grade-a`, `bg-grade-a-soft`, `fill-grade-a`…

| Буква | Баллы | Светлая: текст / фон | Тёмная: текст / фон |
|---|---|---|---|
| A | 90–100 | `#1B7A3A` / `#E3F4E8` | `#51CF66` / `#16301D` |
| B | 82–89 | `#3D7012` / `#EDF5E0` | `#A9E34B` / `#26311A` |
| C | 75–81 | `#0B6E7F` / `#E1F3F6` | `#3BC9DB` / `#0F2D33` |
| D | 67–74 | `#7D5800` / `#FBF0D5` | `#FCC419` / `#33290C` |
| E | 60–66 | `#A14800` / `#FCEBDB` | `#FFA94D` / `#36240F` |
| FX | 35–59 | `#B8321A` / `#FDE8E2` | `#FF8A65` / `#3A1F17` |
| F | 0–34 | `#B42323` / `#FBE3E3` | `#FF6B6B` / `#3A1A1A` |

Контраст текста буквы к своему фону, к `--surface` и `--surface-muted` — от 4.7:1 (светлая) и от 5.6:1 (тёмная).
Цвет — не единственный признак: рядом всегда буква и баллы.

Контраст текста к фону — не ниже 4.5:1 (WCAG AA). Проверено `ui-reviewer` 8 ноября:
`--success` был `#2B8A3E` (3.85:1 на `--success-soft`) → заменён на `#217A36` (4.74:1).
Текст на цветном фоне — без `opacity`: прозрачность съедает контраст.

## 3. Типографика

- Шрифт: **Inter** или **Manrope** (лицензия SIL OFL, есть кириллица).
- Размеры: 28 / 22 / 17 / 15 / 13 px. Основной текст — 15–17 px.

## 4. Иконки

- **Lucide** (лицензия ISC). Иконка без подписи всегда имеет `aria-label`.

## 5. Навигация

| Устройство | Схема |
|---|---|
| Телефон и планшет (< 1024 px) | Шапка сверху (логотип, бейдж, выход) + нижняя панель. Студент: **Сегодня · Расписание · Оценки · Карта · Заявки · Профиль** (6 пунктов, подписи 11 px); сотрудник: **Заявки · Успеваемость · Расписание · Карта**; преподаватель: **Журнал · Расписание · Карта · Профиль**. Контент до 768 px по центру |
| Компьютер (≥ 1024 px) | Боковое меню слева (264 px): логотип, бейдж, разделы, карточка пользователя с кнопкой выхода внизу. Контент до 1152 px |

Пункты меню задаются в одном месте — `lib/navigation.ts` (иконки Lucide: Sun, CalendarDays, GraduationCap, MapPinned,
FileText, UserRound, Inbox, NotebookPen). Оболочка общая для всех ролей (`app/(app)/layout.tsx`).

### Раскладка страниц на компьютере

- Основной контент слева, справочная колонка справа (300–360 px): «Что означают статусы», «Как это работает», шкала статусов заявки.
- Списки на ≥ 768 px — таблица с заголовками колонок; на телефоне — карточки-строки.
- Пары «подпись — значение» (`DetailsList`) — две колонки рядом, а не по краям экрана.
- Вход на компьютере: левая половина — о сервисе (на фоне `--primary`), правая — форма.
- Любая сетка задаётся с `grid-cols-1` / `minmax(0, 1fr)`: иначе длинный текст раздвигает колонку
  и появляется горизонтальная прокрутка на 360 px (такая ошибка уже была).

_План (ещё не сделано):_ колокольчик уведомлений со счётчиком — в шапке на всех экранах.

### LessonCard — карточка занятия

```
┌──────────────────────────────────────────────┐
│ 09:00  [Следующая · через 25 мин] [Отменено] │
│ 10:20  Трансфигурация            ← зачёркнуто, если отменено
│ 1-я пара Лекция
│        Перенесено с 03.11 (1 пара) ← причина (note): оранжевым, у отмены — красным
│        [UserRound] Баранов В.М.             ← полное ФИО и звание — в title и для экранного диктора
│        [Users] 1-ГР-1, 1-ГР-2           ← группы: у потока или в расписании преподавателя
│        [MapPin] ауд. 1017 · Главный корпус ← ссылка /map?room=1017, aria-label «ауд. 1017 · Главный корпус — показать на карте»
│        [Video] Онлайн [Подключиться]  ← target=_blank, rel="noopener noreferrer"
└──────────────────────────────────────────────┘
```

| Состояние | Вид |
|---|---|
| Обычное | без бейджа |
| `cancelled` | бейдж «Отменено» (`--danger`, иконка ✕), время и название зачёркнуты, кнопка онлайн-подключения скрыта |
| `moved` | бейдж «Перенесено» (`--warning`, иконка ⇄) + причина |
| `replaced` | бейдж «Замена преподавателя» (`--warning`) + причина; _план: «было: …» отдельным полем (сейчас — в тексте причины из файла вуза)_ |
| Идёт сейчас | рамка `--primary` + бейдж «Идёт сейчас · ещё 25 мин» |
| Следующая | бейдж «Следующая · через 25 мин» / «в 12:55» (больше 3 часов) |
| Перенесено с этого дня | `MovedAwayCard`: пунктирная рамка `--warning`, бейдж «Перенесено», «Перенесено на 06.11, 4-я пара» — ссылка на тот день; без аудитории. Строится из причины «Перенесено с 03.11 (1 пара)» (`lib/schedule/moves.ts`); другой формат причины — заглушки нет |

Время — по Москве. Ссылки на аудиторию и кнопки — не меньше 44 px по высоте.
Заголовок дисциплины — `h3` на «Сегодня» и в виде «День», `h4` в «Неделе» (там день — `h3`): проп `headingLevel`.
`LessonList` выкладывает карточки в одну колонку; в виде «Неделя» на ≥ 1024 px — в две.

### Экраны расписания

- **«Сегодня»** (`/today?date=…`): ← день → , «Сегодня», выбор даты (`<input type="date">` + «Показать»),
  строка-ответ «Следующая пара в 09:00: Турецкий язык, ауд. 437», плашка об изменениях, список пар;
  пустой день — «Пар нет» + «Ближайшие пары — четверг, 5 ноября». Ниже — заявки.
- **«Расписание»** (`/schedule`): поиск с подсказками и чипами факультетов, «Неделя | День»,
  ← неделя → , «Эта неделя». День без пар в неделе — одна пунктирная строка «нет занятий».
  Подсказки поиска — сразу под полем (чипы факультетов ниже, на телефоне одной строкой с прокруткой):
  при открытой экранной клавиатуре они видны. ↑/↓ — выбор, Enter — открыть (без выбора — первую),
  Esc — закрыть список, второе Esc — очистить; в `aria-live` — «Найдено: N…».
- **«Карта»** (`/map?room=…`): по ссылке на телефоне план открывается крупно («Крупнее»), в окне
  с прокруткой, аудитория — по центру окна, карточка (номер, корпус, этаж, маршрут) — сразу под планом;
  страница прокручивается так, чтобы обе были видны между шапкой и нижним меню. Клавиатура: фокус
  возвращается на нажатую кнопку этажа/корпуса, после выбора — на заголовок карточки, Esc и «Закрыть» —
  на ячейку аудитории. Текст на акценте — `--hm-on-accent` (= `--on-primary`). Ошибка файла карты —
  студенту «Не удалось загрузить карту. Попробуйте позже», подробности — в лог и сотруднику деканата.

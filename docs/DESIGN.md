# Дизайн-система

> Статус: **черновик**. Палитра, шрифт и логотип утверждаются на этапе 1.
> Значения ниже — стартовое предложение, их можно менять.

## 1. Принципы

1. **Сначала телефон.** Макет рисуется на 360 px, потом расширяется.
2. **Ответ, а не таблица.** На каждом экране главное — ответ на вопрос студента
   («Следующая пара через 25 минут, ауд. 305»), детали — ниже.
3. **Изменения заметны.** Переносы, отмены, новые статусы — цветом, иконкой и текстом
   (не только цветом — ради доступности).
4. **Никаких тупиков.** У пустого экрана есть объяснение и действие, у ошибки — кнопка «Повторить».
5. **Спокойный интерфейс.** Один акцентный цвет, много воздуха, минимум рамок.

## 3. Типографика

- Шрифт: **Inter** или **Manrope** (лицензия SIL OFL, есть кириллица).
- Размеры: 28 / 22 / 17 / 15 / 13 px. Основной текст — 15–17 px.

## 4. Иконки

- **Lucide** (лицензия ISC). Иконка без подписи всегда имеет `aria-label`.

## 5. Навигация

| Устройство | Схема |
|---|---|
| Телефон и планшет (< 1024 px) | Шапка сверху (логотип, бейдж, выход) + нижняя панель: Сегодня · Расписание · Учёба · Заявки · Ещё. Контент до 768 px по центру |
| Компьютер (≥ 1024 px) | Боковое меню слева (264 px): логотип, бейдж, разделы, карточка пользователя с кнопкой выхода внизу. Контент до 1152 px |

### Раскладка страниц на компьютере

- Основной контент слева, справочная колонка справа (300–360 px): «Что означают статусы», «Как это работает», шкала статусов заявки.
- Списки на ≥ 768 px — таблица с заголовками колонок; на телефоне — карточки-строки.
- Пары «подпись — значение» (`DetailsList`) — две колонки рядом, а не по краям экрана.
- Вход на компьютере: левая половина — о сервисе (на фоне `--primary`), правая — форма.
- Любая сетка задаётся с `grid-cols-1` / `minmax(0, 1fr)`: иначе длинный текст раздвигает колонку
  и появляется горизонтальная прокрутка на 360 px (такая ошибка уже была).

Колокольчик уведомлений со счётчиком — в шапке на всех экранах.

## 6. Компоненты

| Компонент | Где используется |
|---|---|
| `LessonCard` | расписание, главная; варианты: обычная / перенос / отмена / идёт сейчас |
| `GradeRow` | успеваемость |
| `StatusBadge` | заявки: Подана · В работе · Готова · Выдана · Отклонена |
| `StatusTimeline` | детальная страница заявки: пройденные шаги, текущий, будущие |
| `DetailsList` | пары «подпись — значение»: профиль, детали заявки |
| `AppShell` | оболочка кабинета: боковое меню / шапка + нижняя навигация |
| `NotificationItem` | лента уведомлений |
| `EmptyState` | иллюстрация + текст + кнопка действия |
| `ErrorState` | текст ошибки + «Повторить» |
| `Skeleton` | загрузка любых списков |
| `ConceptBadge` | «Концепт для конкурса» — на каждой странице |

## 7. Тексты интерфейса

- Обращение на «ты» или «вы» — _решить на этапе 1 по итогам опроса_, затем соблюдать везде.
- Коротко и по делу: «Справка готова — заберите в ауд. 112 до пятницы».
- Ошибки — без технических терминов: «Не удалось загрузить расписание. Проверьте интернет».

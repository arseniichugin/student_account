# CLAUDE.md — правила проекта для ИИ-ассистентов

Этот файл читают ИИ-ассистенты (Claude Code и другие) перед любой работой с репозиторием.
Если правило здесь противоречит запросу — уточни у человека, а не нарушай молча.

## О проекте

**«Цифровой деканат будущего»** — прототип личного кабинета студента для конкурса.
Это концепт, а не официальный сервис вуза. Срок работы прототипа — до 28 ноября 2026.

Подробности — в `docs/`:

| Файл | Что внутри | Когда читать |
|---|---|---|
| `docs/PRD.md` | Что делаем, для кого, сценарии и критерии готовности | Перед реализацией любой функции |
| `docs/ARCHITECTURE.md` | Стек, модель данных, правила доступа | Перед изменением сервера, базы, входа |
| `docs/DESIGN.md` | Дизайн-система: цвета, шрифты, компоненты, состояния | Перед любой работой с интерфейсом |
| `docs/ROADMAP.md` | Этапы и текущий прогресс | В начале сессии |
| `docs/AI_LOG.md` | Дневник работы с ИИ | Дополнять в конце каждой задачи |
| `docs/PROMPTS.md` | Шаблоны промптов | Когда ставишь задачу субагенту |

## Стек

Next.js (App Router) + TypeScript · Tailwind CSS + shadcn/ui · PostgreSQL + Prisma ·
сессии в `httpOnly` cookie · argon2 · Docker · VPS в российском облаке.
Не добавляй новые крупные зависимости без объяснения, зачем они нужны.

## Язык

- Интерфейс, документация, комментарии к коммитам — **на русском**.
- Код, имена переменных, таблиц и файлов — **на английском**.

## Жёсткие правила (нарушать нельзя)

1. **Только вымышленные данные.** Никаких реальных ФИО, оценок, номеров зачёток, логинов.
   Не подключаться к настоящим системам вуза. Парсинг открытых данных (расписание) — можно.
2. **Студент видит только свои данные.** Любой запрос к данным студента фильтруется
   по `studentId` из сессии, а не по параметру из URL или тела запроса:
   ```ts
   // ❌ id из адреса без проверки владельца
   db.request.findUnique({ where: { id } })
   // ✅ ищем только среди своих
   db.request.findFirst({ where: { id, studentId: session.studentId } })
   ```
   Права проверяются **на сервере**. Скрытая кнопка в интерфейсе — не защита.
3. **Пароли — только хеш argon2.** Никогда не логировать пароли и токены.
4. **Секреты — только в переменных окружения на сервере.** Никаких ключей в коде,
   в `NEXT_PUBLIC_*` переменных и в браузере. `.env` не коммитится; есть `.env.example`.
5. **Не выдавать за официальный сервис.** На каждой странице виден бейдж «Концепт для конкурса».
   Официальный логотип вуза не использовать.
6. **Только лицензионно чистые материалы.** Новый шрифт, иконку, библиотеку — записать
   в таблицу лицензий в `README.md`.

## Интерфейс

- **Mobile-first.** Всё работает на ширине **360 px**. Проверяй сначала телефон, потом десктоп.
- Каждый экран со списком или данными имеет **три состояния**: загрузка (скелетон),
  пусто (понятный текст + действие), ошибка (что случилось + кнопка «Повторить»).
- Области нажатия — не меньше 44×44 px. У иконок без подписи — `aria-label`.
- Используй токены и компоненты из `docs/DESIGN.md`, а не случайные цвета.

## Как работать

1. Прочитай нужные документы из `docs/`.
2. Если задача больше пары файлов — сначала коротко опиши план.
3. Сделай задачу маленькими шагами; после каждого шага код должен запускаться.
4. Проверь результат: сборка, линтер, тесты, вид на 360 px.
5. Для изменений во входе, доступе к данным или API — запусти субагента `security-reviewer`.
   Для изменений интерфейса — `ui-reviewer`.
6. Добавь запись в `docs/AI_LOG.md` (шаблон внутри файла) и отметь прогресс в `docs/ROADMAP.md`.

# Карта кампуса — модуль личного кабинета

Интерактивная карта без зависимостей: изометрическая схема кампуса и поэтажные планы
(по образцу поэтажных планов реальных вузов, без копирования конфигурации зданий). В кабинете — вкладка «Карта» (`/map`).

| Файл | Что это |
|---|---|
| `public/campus-map/campus-map.js` | компонент: `HogwartsMap.mount(el, { data, onSelect })`, `map.focus('3041')`, `map.show('main', 2)` |
| `public/campus-map/campus-map.css` | стили; цвета — CSS-переменные `--hm-*`, `--t-*`, есть тёмная тема |
| `data/university/campus-map.json` | корпуса и помещения — **заменяемый файл**, формат в `data/university/README.md` |
| `tools/campus-map/build_map_data.py` | пересобирает `campus-map.json` из `tools/schedule-generator/out/schedule.sqlite` (или путь первым аргументом); без базы синтезирует по тем же правилам |

Нумерация: Главный корпус — `ЭКNN` (этаж 1–4, крыло 0 западное / 1 восточное, номер 01–79);
Второй корпус — `ЭNN` (этаж 1–5, номер 01–45); `Обсерватория-N`, `Манеж-N`.
На плане номера идут по возрастанию: сначала по одной стороне коридора от холла (лестницы) к торцу,
затем так же по другой — как на поэтажных планах реальных вузов.

Связь с расписанием: поле `auditorium` в `schedule.json` совпадает с `number` на карте —
`map.focus(lesson.auditorium)` или ссылка `/map?room=3041`.

Данные сгенерированы вместе с синтетическим расписанием (277 помещений, из них 38 служебных:
деканаты, кафедры, администрация; занятий в служебных помещениях нет). Все данные вымышленные.

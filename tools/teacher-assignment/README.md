# Распределение групп по преподавателям

Скрипт `assign_teachers.py` переписывает колонки преподавателя в `data/university/schedule.csv`
так, чтобы у каждой пары **(группа, дисциплина)** был один преподаватель на весь учебный год —
на все виды работ (лекции, практики, семинары, консультации, зачёты, экзамены).
У одного преподавателя может быть сколько угодно групп. Python 3, только стандартная библиотека.

## Запуск

```bash
# распределить и перезаписать файл (по умолчанию data/university/schedule.csv)
python3 tools/teacher-assignment/assign_teachers.py [путь]

# только проверить: код 1, если у пары несколько преподавателей или есть накладки
python3 tools/teacher-assignment/assign_teachers.py --check [путь]

# то же, но неустранимые исключения потоков (см. ниже) тоже считаются нарушением
python3 tools/teacher-assignment/assign_teachers.py --check --strict [путь]
```

После распределения запустите проверку импорта: `npm run data:import -- --check`.

## Что гарантируется

- **Один преподаватель на пару** (кроме неустранимых исключений, см. ниже).
- **Без накладок**: у преподавателя нет двух разных занятий (`lessonOid`), пересекающихся
  по времени в один день. Учитываются все строки, в том числе отменённые и перенесённые.
- У занятия потока (одно `lessonOid`, несколько групп) — один преподаватель на все строки.
- Меняются только 5 колонок преподавателя (`lecturer`, `lecturer_title`, `lecturerOid`,
  `lecturerEmail`, `lecturer_rank`), всегда согласованно — значения берутся из исходной строки
  этого преподавателя. Порядок строк, BOM, разделитель, кавычки и переводы строк сохраняются:
  перед работой скрипт проверяет, что может записать файл байт в байт, иначе останавливается.
- Новых преподавателей не появляется.
- Результат детерминирован: тот же вход — тот же выход. (Повторный запуск на уже
  обработанном файле даёт корректный, но может дать немного другой результат: у
  преподавателей, получивших чужую дисциплину, она становится «своей».)
- Если итог не прошёл проверку, файл не перезаписывается.

## Алгоритм

1. **Единицы назначения.** Пары (группа, дисциплина), связанные общими занятиями потока,
   объединяются (union-find) — иначе у лекции потока было бы два преподавателя.
2. **Параллельные занятия в потоке.** Если две группы одного потока занимаются дисциплиной
   в одно время (две практики в разных аудиториях), один преподаватель на поток физически
   невозможен. Тогда компонента делится: «ядро» — лекции потока и все занятия наибольшего
   набора групп без параллельных занятий (перебор подмножеств, групп в потоке 3);
   оставшаяся группа получает свою единицу из собственных (не потоковых) занятий.
3. **Квалификация.** Кандидаты для единицы — преподаватели, которые уже вели эту дисциплину.
   Время, занятое преподавателем в других его дисциплинах, учитывается.
4. **Перебор с возвратами (DSATUR)** по дисциплинам: сначала единица с наименьшим числом
   допустимых преподавателей; кандидаты по возрастанию стоимости «число занятий, которые
   сменят преподавателя + штраф за превышение средней нагрузки».
5. **Локальное улучшение**: перенос единицы к другому преподавателю и обмен единиц
   между преподавателями, если уменьшается «изменения + разброс нагрузки».
6. **Вне квалификации.** Если дисциплину нельзя распределить своими преподавателями,
   ищется наименьший набор единиц (при равенстве — с наименьшим числом занятий), без
   которого можно; эти единицы получает свободный по времени преподаватель другой дисциплины.
   Кафедр в данных нет, поэтому «та же кафедра» приближена группой дисциплин
   (иностранные языки / остальные), дальше — наименьшая нагрузка.

### Неустранимые исключения (19 пар)

У этих групп есть занятия параллельно с другой группой своего потока, поэтому лекции потока
ведёт лектор потока, а все остальные занятия группы — один другой преподаватель:

1-ГР-3, 1-КГ-3, 1-СЛ-2, 4-ПФ-2 — История магии; 1-ПФ-3, 1-СЛ-2, 4-ГР-3, 4-КГ-3 — Астрономия;
1-ПФ-3, 1-СЛ-2 — Ботаника; 1-ПФ-2, 1-СЛ-3 — Зельеварение; 2-КГ-3, 4-ГР-3, 4-ПФ-3 — Заклинания;
4-ГР-3, 4-КГ-3 — Древняя литература; 3-ГР-2 — Нумерология; 4-ПФ-3 — Пуффендуй: специализация.

Убрать их можно только изменением времени занятий в расписании (генератор в
`tools/schedule-generator/`), но не сменой преподавателя.

# Карта кампуса — модуль личного кабинета

Интерактивная карта без зависимостей: изометрическая схема кампуса и поэтажные планы
(по образцу карты МГИМО, без копирования конфигурации зданий). Открывается по адресу `/campus-map/`.

| Файл | Что это |
|---|---|
| `campus-map.js` | компонент: `HogwartsMap.mount(el, { data, onSelect })`, `map.focus('3041')`, `map.show('main', 2)` |
| `campus-map.css` | стили; цвета — CSS-переменные `--hm-*`, `--t-*`, есть тёмная тема |
| `campus-data.json` / `campus-data.js` | помещения (JSON для fetch, JS — для подключения тегом `<script>`) |
| `index.html` | пример страницы |
| `../../scripts/build_map_data.py` | пересобирает данные из `data/mgimo_schedule.sqlite` (или путь первым аргументом); без базы синтезирует по тем же правилам |

Нумерация: Главный корпус — `ЭКNN` (этаж 1–4, крыло 0 западное / 1 восточное, номер 01–79);
Второй корпус — `ЭNN` (этаж 1–5, номер 01–45); `Обсерватория-N`, `Манеж-N`.
На плане номера идут по возрастанию: сначала по одной стороне коридора от холла (лестницы) к торцу,
затем так же по другой — как на поэтажных планах МГИМО.

Связь с расписанием: поле `auditorium` в `schedule.json` совпадает с `number` на карте —
`map.focus(lesson.auditorium)` или ссылка `/campus-map/#room=3041`.

Данные сгенерированы вместе с синтетическим расписанием (277 помещений, из них 38 служебных:
деканаты, кафедры, администрация; занятий в служебных помещениях нет). Все данные вымышленные.
